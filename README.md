# ЛР3 — поиск в RAG
ЛР3 использует данные, индекс, промпты и модель соседней lab2. ЛР2 и ЛР1 должны лежать рядом. Поиск выполняется на CPU. Перед проверкой holdout сохраняется выбор по dev.
Запуск из PowerShell: .\run.ps1
Подготовка отчёта после завершения: ..\lab2\.venv\Scripts\python.exe finalize.py
Результаты поиска, генерации и метрики сохраняются в results. Незавершённая генерация продолжает только отсутствующие запросы. Сохранённые ошибки остаются частью оценки.
