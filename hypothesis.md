# Прогноз до опытов
BM25 поможет там, где важны точные совпадения редких названий и обозначений. Dense лучше справится с перефразированием. RRF может сохранить находки обоих методов, но иногда понизит документ, найденный только одним методом. Cross-encoder может улучшить порядок, но это не гарантирует улучшение ответов после ограничения контекста.
Выбор на dev среди BM25, RRF, RRF+CE: максимум MRR@3, затем Recall@3, затем простота в указанном порядке. Holdout используется только после записи selection.json.
